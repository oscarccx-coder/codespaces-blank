Apollo persistent storage

databases/    SQLite knowledge, memory and runtime databases
state/        Small persistent JSON/state files and Hub layout
cache/        Rebuildable caches and temporary working data
media/        Screenshots, generated audio and voice profiles
models/       Local model assets managed by Apollo
training/     Training datasets and research material
environments/ Isolated Python environments
reports/      Benchmarks and generated reports
backups/      Recovery and update/module backups
trash/        Recoverable deleted files
updates/      Update client/server state, staged releases and logs
logs/         Runtime/error logs
legacy_conflicts/ Preserved conflicts found during migration
