# Apollo Future Feature Blueprints

These folders are **placeholders**, not installed modules.

They give Apollo a machine-readable starting contract for planned features before implementation begins. Each feature has:

- `feature.json` — target version, dependencies, planned tools and acceptance criteria.
- `module.py.template` — a deliberately inert module skeleton.

When development starts, Apollo should copy the relevant blueprint into a pending candidate, implement it, validate it, and only then promote it through the normal certification/approval path.
