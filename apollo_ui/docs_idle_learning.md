# Idle self-study

Keep Apollo open. In Apps → Practice & learning, authorise public research and choose **Start idle self-study**. An empty title/goal uses a bounded topic about local AI memory, retrieval and reasoning; an entered goal is retained. Choose a destination node or automatic Research/topic storage.

This creates an until-stop practice mission with a persisted idle-only setting. It waits for five minutes without Apollo keyboard, mouse-button, wheel or touch input. Active chat defers new learning batches. A batch already in progress may finish; this is not instantaneous cancellation or an operating-system CPU-idle detector.

Existing source permissions, exact quotation checks, application practice, duplicate suppression, memory retry and the 24-batches-per-mission UTC daily budget still apply. Pause/stop prevents further batches, including after restart. Errors remain visible. Saved lessons remain unverified research; no model weights are trained, code auto-installed, paid models invoked or production changes approved.

The tracker observes Apollo input events only, not screen contents or other programs. Tracking must be attached to the GUI; headless idle missions wait rather than assuming the owner is away. The app/PC must remain running. Existing normal missions keep their schedule, but new batches also yield during chat.
