Apollo 7.5.02 — Dual-Pane File Manager + Close Button

INSTALL
-------
1. Close Apollo.
2. Extract this patch into the Apollo root and replace matching files.
3. Keep your storage, workspace, pending_modules and config.json.
4. Start Apollo.

NEW
---
- Top-right in-app Close Apollo button.
- Files page has two independent panes.
- Drag Apollo files/folders between panes to MOVE them on the real filesystem.
- Drop Windows Explorer files/folders into a pane to COPY/import them.
- Multi-select Move/Copy buttons in both directions.
- Core files stay protected and delete still uses recoverable Apollo trash.

The patch does NOT include config.json, storage/, workspace/, pending_modules/,
ui_state.json or modules_state.json.
