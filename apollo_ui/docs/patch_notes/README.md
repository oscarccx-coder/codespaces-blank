# Apollo Patch Notes

This directory holds Apollo's release history and patch instructions. The main
application folder is reserved for startup files and importable Python modules.

- [Current UI overhaul and repository cleanup](2026-10-10_UI_USABILITY.md)
- [Consolidated version history](PATCH_NOTES.md)
- [Archived root-level copies](legacy_root_files/)
- Historical `PATCH_README_*.txt` notes remain here for reference.

When Apollo starts, `apollo_docs.PatchDocs` also migrates older installations'
root-level `PATCH_NOTES.md` and `PATCH_README*.txt` files here, preserving
conflicting copies in the archive instead of deleting user changes.
