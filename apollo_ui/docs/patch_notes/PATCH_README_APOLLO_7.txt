Apollo 7.0 Full Patch

BASE: Apollo V6.6.25 or later in this project line.

INSTALL
1. Close Apollo.
2. Back up the entire Apollo folder.
3. Extract this patch over your Apollo root and allow file replacement.
4. Do NOT delete your storage folder, workspace, config.json or databases.
5. Run install.bat once (Apollo 7 adds pyserial).
6. Start Apollo normally.
7. Open Settings -> Apps -> Control Center and review permissions.

High-risk abilities start blocked. This is intentional.

For a safer Windows EXE build, use build_apollo_exe_safer.bat. See README_EXE_SAFETY.txt.
