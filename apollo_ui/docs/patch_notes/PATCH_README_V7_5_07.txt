Apollo 7.5.07 — Persistent Project Context

INSTALL
-------
1. Close Apollo.
2. Extract this patch over Apollo 7.5.06.
3. Replace matching files.
4. Keep config.json, storage/, workspace/, pending_modules/, ui_state.json and modules_state.json.
5. Start Apollo.

WHY THE FOLLOW-UP FAILED
------------------------
7.5.06 used the current in-memory chat to identify GravityLab. Installing/restarting
Apollo clears that volatile context even though workspace/GravityLab still exists.

7.5.07 stores the active project in:

storage/active_project.json

This file is generated by Apollo and survives future patches.
