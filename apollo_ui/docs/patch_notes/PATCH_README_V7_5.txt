Apollo 7.5 — Coordination & OS Integration FULL PATCH

Install over Apollo 7.0.1 or later in this project line.

1. Close Apollo.
2. Extract this patch into the Apollo root and allow file replacement.
3. DO NOT delete/replace storage, workspace, config.json, ui_state.json or your databases.
4. Run install.bat once if you have not already installed V7 requirements.
5. Start Apollo.

The patch excludes config.json, ui_state.json, modules_state.json, storage/, workspace/ and pending_modules/.

File Manager appears as a sidebar app named Files. It operates on the real filesystem; moves/renames update Windows immediately, delete is recoverable trash, and core files are protected. Scan Misplaced suggests likely wrong locations but moves nothing automatically.

Apollo 7.5 also adds Context Manager, Task Engine, Verification Engine, Capability Graph, Knowledge Graph, Activity Trace, Benchmark Suite, Upgrade History, Background Intelligence, model role profiles, isolated dependency environments and multi-file self-improvement proposals.
